# 🛡️ KNOX Official — Luxury E-Commerce Frontend UI

A bespoke, high-end frontend layout designed exclusively for **KNOX**, a premium minimalist metal/carbon-fiber wallet and luxury fragrance brand. This project features a dark-mode luxury aesthetic tailored for WordPress/WooCommerce custom integrations.

---

## ✨ Key Features
* **Luxury Dark Theme:** Styled with deep charcoal gradients (`#020202`), matte black panels, and sophisticated gold accents (`#d4af37`).
* **Typography:** Integrated Google Fonts (`Cinzel` for high-end serif headings and `Plus Jakarta Sans` for clean, modern body text).
* **Responsive Grid:** Fully responsive 3-column product showcase grid optimized for desktop, tablet, and mobile displays.
* **Direct Call-to-Actions:** Embedded WhatsApp direct-order buttons with pre-filled checkout text alongside standard WooCommerce cart buttons.
* **Brand Identity:** Showcases the signature tagine *"Heritage of Distinction"*.

---

## 🛠️ Tech Stack
* **HTML5** (Structure)
* **CSS3 / Inline Custom Styling** (Advanced layout overrides, Flexbox, Grid, Google Fonts import)
* **WordPress / WooCommerce UI Snippet** (Compatible with custom page layouts)

---

## 🚀 Preview / Usage
This code is built to serve as a custom frontend injection or standalone shop layout for WordPress environments utilizing custom CSS blocks.
